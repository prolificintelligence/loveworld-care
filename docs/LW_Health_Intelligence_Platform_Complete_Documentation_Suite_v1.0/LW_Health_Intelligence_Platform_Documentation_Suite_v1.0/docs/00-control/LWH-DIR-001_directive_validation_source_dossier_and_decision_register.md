## Validation and change procedure

The analyst reviews directives with the Director's nominee, records exact disputed wording and asks for source templates. Each decision records proposer, authorised decider, effective version, rationale, evidence and affected IDs. A new interpretation never overwrites the original evidence. Accepted changes propagate to business requirements, policy, PRDs, fields, metrics, tests and training. Open authority affects activation, while fully specified draft workflows allow development and synthetic evaluation to proceed.
