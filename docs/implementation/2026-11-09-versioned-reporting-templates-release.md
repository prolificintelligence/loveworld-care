## Delivered capability

The project owner instructed implementation to proceed with a researched initial form because the Directorate originals are unavailable. The [live template workspace](https://lw-health-intelligence.vercel.app/reporting-templates) supplies **LWH-WORKING-2026.1**: a monthly facility form with **15 measures**, a zone community form with **three**, and a regional coordination form with **four**. The [Director review pack](reporting-forms/README.md) includes definitions, inclusion/exclusion rules, source registers, aggregation methods, the proposed calendar, a JSON package and three CSV field dictionaries. Six primary WHO/Nigerian professional-council references inform the original design. The selected event cut-offs and 5/10/15 monthly calendar are implementation proposals. These are usable working forms proposed for Director review, not claimed original or approved Directorate documents, WHO endorsements or national submission equivalents.

Facility measures cover contacts, distinct local people, coded-condition contacts, inpatient deaths/mortality, care access/unmet demand, follow-up, staffed service coverage, readiness, referral acceptance/outcomes, critical-result follow-through, essential product-day stockouts and staffed bed occupancy. Zone measures separate education delivery, community interventions and serviceability; regional measures cover registry coverage, corrective completion, renewal timeliness and interventions. Community activity is not added to clinical contacts. The initial condition-code profile does not estimate disease incidence or implement disease-specific surveillance forms.

A currently authorised global Data Governor selects a form and records actual provisional configuration authority and validity. One idempotent transaction creates immutable indicator versions and a **DRAFT** mapping. Those definitions use existing governor-adoption authority; the template still requires submission, examination by a different person and explicit adoption. Any contributor to the mapping is excluded from independent review, including after a second contributor edits it. A governor cannot adopt their own review. Draft corrections retain versions; submitted/adopted mappings are frozen.

Every source field has a unique code and an exact measure-component mapping, context, justified exclusion or explicit gap. Gaps, incomplete ratios, duplicate metric versions and missing comparison totals block acceptance. The [obligation form](https://lw-health-intelligence.vercel.app/directorate) can select an adopted template. The API validates its exact edition, period, stream, jurisdiction and indicator set, then freezes the complete mapping. Withdrawal blocks new use while earlier obligations and returns retain their meaning. Existing definition-based obligations explicitly display their absent binding and preserve earlier receipt canonicalisation. Template/history reads are paginated; searchable indicator lookup and exact embedded definitions support catalogues exceeding 500 versions.

Future original institutional forms can be inventoried through the same workflow. External originals' fingerprints remain author-attested: this increment does not upload, fetch or malware-scan them. The built-in proposal fingerprint is the canonical API JSON digest, recorded in the review pack. No template, reporting calendar, clinical value or independent Director decision is automatically adopted or fabricated in production. Manual/controlled CSV capture is the initial source path; the existing native completed-contact extractor remains available under its separately adopted exact definition.
