# Qualified native EMR reporting release

Date: 9 November 2026. This increment extends the Director-first reporting sequence with qualified native mappings and current-source checks. Actual Director adoption and clinical/institutional operating acceptance remain separate.

## Implemented outcome

[Reporting templates](https://lw-health-intelligence.vercel.app/reporting-templates) now includes **LWH-NATIVE-2026.1**: four exact source profiles for completed native service contacts (010), inpatient deaths (013), institutional inpatient mortality proportion (014), and actual referral acceptance (025). The [source guide](native-reporting-source-guide.md) specifies inclusion, source/cut-off rules, exclusions, configuration and correction steps; its [JSON contract](reporting-forms/LWH-NATIVE-2026.1.json) retains the exact version. The original 22-indicator working-form package is unchanged.

An authorised governor explicitly configures the exact immutable definitions and a DRAFT mapping. Independent template review and adoption still precede template-bound obligations. Changed source semantics cannot be attached to one of these native selectors. No clinical case definitions, institutional approval, production template adoption or source values are invented.

The extract verifies clinical event hashes, Ed25519 signatures, ordered version chains and agreement with current source projections. Counts use actual occurrence times and signed same-patient/encounter summaries. Inpatient final outcomes are distinct from open stays, ward transfer, leave and bed release; actual receiving acceptance is distinct from a sent referral and must meet the frozen cut-off. Cancellation before acceptance is excluded with accounting, while later cancellation does not erase an acceptance. Ratios preserve numerator and denominator; an equal percentage with changed components remains a reviewable discrepancy.

In [Directorate returns](https://lw-health-intelligence.vercel.app/directorate), extraction produces a retained preview. The officer explicitly applies it to the draft, replacing only mapped fields and retaining actual components and missingness. Native totals start **PARTIAL** until full-source coverage is examined. Unusable activation/source evidence or denominators produce **UNKNOWN**; an empty native source is not silently declared whole-facility NIL. Manual values are not automatically added. Submission and independent verification remain separate.

Source references and event heads are retained in an encrypted append-only manifest. Reporting responses withhold patient IDs, chart narrative and receiving-person identities. Scoped source reviewers can inspect retained aggregate extracts and their current eligibility; executive-only users cannot access source extracts by seniority. Leadership remains protected by the existing independently reviewed disclosure policy and snapshot release.

Period-relevant source/summary/error-marker or activation changes invalidate current use. Unrelated later-period care does not stale an earlier return. Submission, independent verification and new snapshot preparation/release reject stale linked extracts. Already released cells remain historical evidence, explicitly labelled **STALE_CLINICAL_SOURCE_CHANGE**, with `current_eligible=false` in the API and the same freshness in CSV. A new extract and retained return correction, followed by review/release, are required to establish a renewed current result.

## Remaining scope and next sequence

The native source operation has explicit configured bounds of 5,000 relevant-kind records and 20,000 events per facility inventory. Above those bounds it refuses the synchronous batch rather than returning a truncated aggregate. Those limits are not proof of representative maximum-volume performance; wider batch/load qualification remains open. Current eligibility is checked at decisions/reads rather than by a new continuous external worker.

This delivers four source mappings, including a stronger completed-contact profile; it does not automate all 22 proposed indicators or all 45 suite metrics. Distinct-person reconciliation, disease-specific approved case/coding definitions and dimensions, other source mappings, representative data-volume/accessibility checks and actual source-coverage adoption remain work. Full-facility completeness, population disease incidence, certified cause of death and referral completion are not inferred from these extracts.

Next priorities remain: actual Director review/configuration of the proposed forms, roster/facility/officer/calendar/disclosure adoption; further qualified native source mappings; observed officer capture through independent verification and permitted leadership release; and accountable intervention/correction journeys. The native EMR requires no second EMR. Equipment connections follow facility registration/approval and adopted service readiness. Wider patient referral tracking/remote-care channels, sponsorship and governed assistance retain their separate backlog. Offline care remains core; facility-local installation and extra persistent hosting remain deferred.

The 25-PRD matrix remains **22 Partial, one Not delivered, one Infrastructure only and one optional/deferred**. The formal 200 requirements and 111 specified acceptance cases retain their original NOT_RUN statuses; engineering evidence does not imply full-suite operating acceptance. [ADR-0018](../adr/0018-qualified-native-reporting-and-current-source-checks.md) records this decision.
